# Movie Builder — M1 Technical Prototype

Standalone Movie Builder renderer plus a draft installable ChatGPT Skill (`SKILL.md`, `agents/openai.yaml`, bundled `scripts/`). Work-in-progress: not yet a complete story-to-video pipeline.

## Requirements
Python 3.10+, FFmpeg and ffprobe (with libx264 + AAC), Pillow for generating demonstration cards.

## Reproduce
```bash
python -m pip install Pillow
python movie_builder/make_demo.py /tmp/mb-demo
python movie_builder/renderer.py /tmp/mb-demo/project.json /tmp/mb-demo/output.mp4
```

Inputs: project.json containing `audio`, `shots:[{image,duration}]` **or** `shots:[{image,end_frame}]` (absolute, exclusive integer frame boundaries for every shot), optional `fps,width,height`. Relative image/audio paths are resolved relative to project.json. Output is an MP4, matching `.qa.json` report, and a labeled `.contact_sheet.png` preview of input shots. The contact sheet is a storyboard preview, **not** an encoded-frame timing proof.

## Verified test — 2026-10-14

## Encoded-frame regression (PR #7)

`movie_builder/tests/test_encoded_cuts.py` creates four solid-color shots at 30 fps, renders two seconds of video and decodes MP4 frames numbered 0, 14, 15, 29, 30, 44, 45, 59. It asserts the center pixel belongs to the intended shot on either side of every boundary. This tests *encoded MP4 cuts* rather than relying on the source-image contact sheet. The repository also contains `.github/workflows/movie-builder-tests.yml` to execute both regression modules on Movie Builder PRs.

**Verification status (2026-10-14):** The full nine-test Movie Builder suite passed locally using FFmpeg 7.1.5 and Pillow 12.3.0, including this decoded-cut test. GitHub CI has not been confirmed successful; inspect [PR #7](https://github.com/steveonw/movie-skill-for-ai/pull/7) checks before merging.

## Current constraints
- Timing is supplied as durations or already-compiled absolute `end_frame` boundaries; no automatic narration alignment or word-level timing.
- No images are generated by AI; only placeholder cards.
- Audio/shot discrepancy greater than one video frame is rejected. Short audio is padded, slightly longer audio extends the last still, and final AAC audio packets are preserved; unusual codecs and VBR metadata still warrant QA.
- Source-image contact sheet is automatic; it does not verify actual encoded cut times. No captions, transitions, precision word anchor, cache, or full technical test suite yet.
- No need for other Skills; no paid services.


## ChatGPT Skill 3 (draft package, 2026-10-14)

The Movie Builder Skill now has `movie_builder/SKILL.md`, `agents/openai.yaml`, and bundled `scripts/` for standalone installation. The bundle supports input shots and supplied narration rather than depending on Story Director or Narration Studio. To package independently, use the ChatGPT skill packaging validator on `movie_builder/`; its included scripts require Python, Pillow, FFmpeg and ffprobe on the execution host.

`verify_cuts.py` inspects **decoded output frames immediately before and at** each planned cut, comparing to input stills. Test with `python -m unittest discover -s movie_builder/tests -v`. Encoded-frame detection is not the same as speech/word timing verification and can become ambiguous when adjacent source stills are visually similar.

## Frame safety and narrated-media proof (2026-10-14)

- **Cumulative rounding:** `duration` mode calculates cumulative absolute boundaries before converting to frames, avoiding drift from rounding every shot independently. `end_frame` mode accepts explicit exclusive end frames when a producer has already compiled a schedule; do not mix the two modes.
- **MP3 metadata:** compute effective audio length using decoded `nb_samples` (plus sample rate) rather than raw MP3 container duration, which can include encoder padding. Probe metadata and decoded duration are both reported in `.qa.json`.
- **No premature stop:** audio is padded/truncated only to the computed *visual* duration after confirming the final frame covers the input. The last visual still is extended by up to a frame if audio is slightly long. `-shortest` was removed after tests demonstrated it could drop the last AAC packet. More-than-one-frame mismatches still fail before encoding.
- **Executed local tests:** `python -m unittest discover -s movie_builder/tests -v`: **9 tests passed** (including earlier encoded-cut test, clip mismatch rejection, exact-frame mode, short and long audio, MP3 delay, final audible signal, and invalid timelines). Local environment: Python 3.13.5, FFmpeg 7.1.5, Pillow 12.3.0. Exact GitHub CI status not asserted.
- **Spoken test:** rendered a **16.316s** locally synthesized spoken narration with three text cards to a 1280x720, 30-fps H.264/AAC MP4 (490 frames); decoded before/after-boundary checks all passed. Its cuts are illustrative, **not aligned to individual words**, and this does not imply narration or image synthesis is part of the packaged Skill.
