# Movie Builder — M1 Technical Prototype

First independent Movie Builder executor, intentionally not an installable Skill yet.

## Requirements
Python 3.10+, FFmpeg and ffprobe (with libx264 + AAC), Pillow for generating demonstration cards.

## Reproduce
```bash
python -m pip install Pillow
python movie_builder/make_demo.py /tmp/mb-demo
python movie_builder/renderer.py /tmp/mb-demo/project.json /tmp/mb-demo/output.mp4
```

Inputs: project.json containing `audio`, `shots:[{image,duration}]`, optional `fps,width,height`. Relative image/audio paths are resolved relative to project.json. Output is an MP4, matching `.qa.json` report, and a labeled `.contact_sheet.png` preview of input shots. The contact sheet is a storyboard preview, **not** an encoded-frame timing proof.

## Verified test — 2026-10-14
FFmpeg 7.1.5, Python 3, 5 generated PNGs at 640x360, mono 48 kHz 7s WAV (synthetic sound), five 1.4s shots -> H.264/AAC MP4 with `ffprobe` showing 7.000000s duration; expected 210 frames. Actual MP4 was created in the assistant's sandbox. **This is a technical demo, not text-to-video filmmaking, word-level audio sync, or semantic QA.**

## Regression checks

```bash
python -m unittest discover -s movie_builder/tests -v
```

Additional local verification (2026-10-14, revised renderer): five PNGs plus seven-second WAV produced 210 expected/actual frames, H.264/AAC MP4, 7.0 seconds, and contact sheet. A deliberately shortened shot timeline was rejected with `Audio/shot mismatch`. Regression test is committed but must be independently run by CI/another session before calling it a repository-verified test.

## Current constraints
- Timing is supplied manually as seconds; no speech alignment.
- No images are generated by AI; only placeholder cards.
- Audio/shot duration discrepancy greater than one video frame is rejected before rendering. Very small container padding and timestamp nuances still require additional real-media tests.
- Source-image contact sheet is automatic; it does not verify actual encoded cut times. No captions, transitions, precision word anchor, cache, or full technical test suite yet.
- No need for other Skills; no paid services.
